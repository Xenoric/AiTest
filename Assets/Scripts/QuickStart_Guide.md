## ⚡ Быстрая настройка

### 1. Настройка слоев препятствий

В **SimpleBotManager** установите `obstacleLayerMask`:
- Включите слои: `Obstacle`, `Team1`, `Team2` (для избегания других ботов)
- Исключите слои: `UI`, `Default`

### 2. Базовые параметры расстояния

Рекомендуемые значения для начала:
```
Min Distance: 2.0
Max Distance: 5.0  
Optimal Distance: 3.5
```

### 3. Параметры видимости

```
Line of Sight Distance: 10.0
Check Interval: 0.2
```

## 🎮 Тестирование в игре

### Добавьте BotBehaviorTester:

1. Создайте пустой GameObject в сцене
2. Добавьте компонент `BotBehaviorTester`
3. Запустите игру
4. Используйте GUI для настройки параметров в реальном времени

### Что наблюдать:

- **Зеленые линии** = боты видят свои цели
- **Красные линии** = видимость заблокирована  
- **Цветные окружности** = зоны расстояний
- **Желтые сферы** = альтернативные цели для обхода

## 🔧 Настройка поведения

## 🐛 Отладка проблем

### Боты не двигаются:
- Проверьте, что `useAvoidanceFollower = true` в SimpleBotManager
- Убедитесь, что цели назначены корректно
- Проверьте NavAgent компоненты на префабе бота

### Боты игнорируют препятствия:
- Настройте `obstacleLayerMask` правильно
- Убедитесь, что препятствия имеют Collider2D
- Проверьте, что слои настроены в Project Settings

### Боты ведут себя странно:
- Используйте отладочную визуализацию (выберите бота в сцене)
- Проверьте логи в консоли
- Настройте параметры через BotBehaviorTester

## 📊 Мониторинг производительности

### Оптимизация:
- Увеличьте `lineOfSightCheckInterval` для лучшей производительности
- Уменьшите `lineOfSightDistance` если не нужна дальняя видимость
- Настройте `obstacleLayerMask` только на нужные слои

### Рекомендуемые значения для 20+ ботов:
```
lineOfSightCheckInterval = 0.3f
pathUpdateInterval = 0.4f
```
