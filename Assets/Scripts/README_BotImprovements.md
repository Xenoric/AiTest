# 🤖 Улучшения системы ботов

## 📋 Обзор изменений

Система ботов была значительно улучшена для обеспечения более реалистичного и интеллектуального поведения:

### ✨ Новые возможности

1. **Контроль расстояния** - боты поддерживают оптимальное расстояние до цели
2. **Проверка прямой видимости** - боты учитывают препятствия между собой и целью
3. **Альтернативные пути** - поиск обходных маршрутов при отсутствии прямой видимости
4. **Улучшенная отладочная визуализация** - наглядное отображение состояний ботов

## 🎯 Контроль расстояния

### Параметры:
- **minDistanceThreshold** (2.0f) - минимальное расстояние до цели
- **maxDistanceThreshold** (5.0f) - максимальное расстояние до цели  
- **optimalDistance** (3.5f) - оптимальное расстояние для поддержания

### Поведение:
- Если бот **слишком близко** (< min) → отступает до оптимального расстояния
- Если бот **слишком далеко** (> max) → приближается до оптимального расстояния
- Если бот **в диапазоне** (min ≤ distance ≤ max) → поддерживает текущую позицию

## 👁️ Система прямой видимости

### Параметры:
- **lineOfSightDistance** (10.0f) - максимальная дистанция проверки
- **obstacleLayerMask** - слои препятствий (стены, другие боты)
- **lineOfSightCheckInterval** (0.2f) - интервал проверки видимости

### Логика работы:
1. **Raycast проверка** каждые 0.2 секунды
2. **Обнаружение препятствий** между ботом и целью
3. **Поиск альтернативного пути** при отсутствии прямой видимости
4. **Сохранение последней известной позиции** цели

## 🔄 Алгоритм поиска альтернативного пути

При обнаружении препятствия:

1. **Определение точки препятствия** через Raycast
2. **Вычисление перпендикулярных направлений** для обхода
3. **Тестирование кандидатов** на свободность пути
4. **Выбор оптимального маршрута** ближайшего к цели

### Кандидаты для обхода:
- Перпендикулярно влево от препятствия
- Перпендикулярно вправо от препятствия  
- Диагонально влево-вперед
- Диагонально вправо-вперед

## 🎮 Настройка в SimpleBotManager

### Новые параметры в инспекторе:

```csharp
[Header("Контроль расстояния")]
public float minDistanceThreshold = 2.0f;
public float maxDistanceThreshold = 5.0f; 
public float optimalDistance = 3.5f;

[Header("Проверка видимости")]
public float lineOfSightDistance = 10.0f;
public LayerMask obstacleLayerMask = -1;
public float lineOfSightCheckInterval = 0.2f;
```

## 🎨 Отладочная визуализация

При выборе бота в сцене отображаются:

- **Зеленая линия** - прямая видимость есть
- **Красная линия** - прямая видимость заблокирована
- **Красная окружность** - минимальное расстояние
- **Зеленая окружность** - оптимальное расстояние
- **Синяя окружность** - максимальное расстояние
- **Желтая сфера** - альтернативная цель (если используется)
